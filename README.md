# One 2b Investor Experience

Three build surfaces for the One 2b visual system:

1. `01-vite-react/` — standalone Vite + React investor experience.
2. `02-framer-components/` — portable React components for Framer Code Components.
3. `03-plain-html-css-js/` — portable static HTML/CSS/JS version.

Brand direction:
- White base
- Soft pastel gradient: lavender #EAE4F4 → periwinkle #D2DCEC → peach #F1DDD0
- Deep navy display ink #1B2540
- Body slate #4A5266
- Premium institutional, soft authority, editorial whitespace
- No dark institutional default
- No glassmorphism
- No crypto-purple
- No neon blues
- No SaaS dashboard aesthetic

Terminology discipline:
- IGI (Insurance Guarantee Instruments)
- Tesseract
- Mozambique pilot, Colombia expansion
- USD or EUR only
- Asterisks on every yield/return claim
